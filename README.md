# README

## Project: Bank Simulation (CS4348 - Operating Systems)

This project simulates a bank with multiple customer and teller threads, demonstrating synchronization and concurrency concepts using Python threading and semaphores.

---

## Files:
- `bank_simulation.py` — The main simulation script.
- `devlog.md` — Development log tracking all progress made throughout the project.

---

## How to Run:

1. Requirements: Python 3.x
2. To execute:
```bash
python3 bank_simulation.py
```
3. No additional libraries or dependencies required. This runs on standard Python libraries.

---

## Notes for the TA:
- The program uses proper synchronization primitives to protect shared resources like the manager, safe, and bank entrance.
- Logging format strictly follows the specified output style from the project description.
- The simulation includes randomized delays to mimic realistic interactions.
- The program gracefully terminates once all customers are served.

---

Tested and works on `cs1` and `cs2` machines. No external dependencies or IDE configurations are required.
